
# Python and Bash Assignment

## Objective
Practice Python conditionals, dictionaries,
and file handling.

## Programs
1. grade_checker.py - Determines grades from scores.
2. student_grades.py - Manages student grades.
3. write_file.py - Writes content to sample.txt.
4. read_file.py - Reads content from sample.txt.

## Requirements
- Python 3

## How to Run
python grade_checker.py
python student_grades.py
python write_file.py
python read_file.py

Note: Run write_file.py before read_file.py.
